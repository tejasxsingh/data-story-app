# Interactive Data Story Web App

This project demonstrates an interactive data-driven storytelling interface built using **Streamlit**, **Pandas**, and **Altair**.  
It visualizes global internet usage trends and allows users to explore how connectivity has evolved across regions.

---

## Live Demo
[Open the app here](https://data-story-app-tejasxsingh.streamlit.app)

---

## Features
- Interactive dropdown to explore regions  
- Dynamic line chart visualization using Altair  
- Streamlit caching for fast and efficient data loading  
- Simple, clean, and responsive design  

---

## Tech Stack
- Python  
- Streamlit  
- Pandas  
- Altair  

---

## Dataset
A small sample dataset (`data/internet_usage.csv`) is included with the app to demonstrate interactive visualizations.  
You can replace it with your own data to create new stories or analytics dashboards.
